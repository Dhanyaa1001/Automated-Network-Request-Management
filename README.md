# Automated-Network-Request-Management
Project Documentation and Demonstration for Automated Network Request Management in ServiceNow


**About the Project**

Automated Network Request Management in ServiceNow is a ServiceNow-based project that automates the process of submitting, approving, tracking, and fulfilling network requests.

The project uses Service Catalog and Flow Designer to provide a structured and efficient request management process.

**Objectives**

* Automate network request management
* Simplify request submission
* Automate approval and notification processes
* Improve request tracking and visibility
* Reduce manual effort and errors
* Maintain organized and audit-ready records
  
**Key Features**

* Network Request catalog item
* Dynamic request form
* Request validation
* Approval workflow
* Automated email notifications
* Fulfillment task creation
* Request status tracking
* Role-based access
* Flow Designer automation
  
**Technology**

* ServiceNow
* Service Catalog
* Flow Designer
* Service Portal
* ACLs
* Email Notifications
